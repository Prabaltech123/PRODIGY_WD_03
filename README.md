# Tic-Tac-Toe Game

## Prodigy InfoTech Internship – Task 3

### About the Project
This is a web-based Tic-Tac-Toe game developed as part of my Prodigy InfoTech Web Development Internship.

The project recreates the classic Tic-Tac-Toe game with an interactive interface where players can compete against each other.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Features
- Interactive game board
- Two-player gameplay
- Automatic winner detection
- Draw detection
- Restart game option
- User-friendly interface

### How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
